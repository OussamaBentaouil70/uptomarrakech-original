# Up To Marrakech

Static Next.js site (Cloudflare Pages) that replaces the former WordPress site of uptomarrakech.com.
Same URLs as WordPress (French by default, English under `/en/`), no database: all content is JSON in `data/`.

## Edit content

| What | File |
|---|---|
| Products (villas, restaurants, spas, …) | `data/content/products.json` |
| Villa location / bedrooms / guests / price | `data/villa-details.json` |
| Blog articles shown (9 FR + 9 EN) and the product each one links to | `data/blog-keep.json` |
| Text + image sections on category pages (FR/EN) | `data/category-sections.json` |
| Menu, footer links, partners, phone, email, socials | `src/lib/site.ts` |

After editing anything in `data/raw`, `data/blog-keep.json` or `data/villa-details.json`, regenerate with `npm run content`.
Then commit and push: Cloudflare Pages rebuilds and publishes automatically.

## Commands

```bash
npm install
npm run dev          # local development (http://localhost:3000)
npm run content      # rebuild data/content/*.json, public/_redirects, sitemap, search index
npm run build        # static export to out/
npm run preview:cf   # serve out/ like Cloudflare (needs a build first; secrets in .dev.vars)
```

## Email

`functions/api/send-email.ts` (Cloudflare Pages Function) sends the form emails through the Brevo API
(`BREVO_API_KEY`, `FROM_EMAIL`, `ADMIN_EMAIL` …). Locally without `BREVO_API_KEY` it uses Nodemailer/SMTP.

## SEO

- Every URL indexed by Google on the WordPress site is either a page here or a 301 in `public/_redirects`.
- Titles, descriptions and structured data come from the original Rank Math tags (`data/seo.json`).
- `public/sitemap.xml` and `public/robots.txt` are generated by `npm run content`.
